# Caterham Seven Championship UK — 2026

Standings, race-by-race points and session timings for the 2026 MOTUL
Caterham Seven Championship UK.

**This repository is generated.** `index.html` is a single
self-contained page published automatically from a private repository
that holds the scrapers and the source documents. Edits here will be
overwritten on the next publish.

Results come from [TSL Timing](https://www.tsl-timing.com/) and the
[Spa Euro Race](https://ser2026.racspa.be/) (Alkamel Systems); the
calendar and judicial decisions from
[BARC](https://www.barc.net/championship/caterham-seven-championship-uk/);
points are computed from the
[2026 Championship Regulations](https://caterhamcars.com/assets/Documents/Seven%20Championship%20Documents/2026%20Caterham%20Seven%20Championship%20UK%20Regulations%20-%20Published.pdf).

Provisional until declared final by the organisers.
